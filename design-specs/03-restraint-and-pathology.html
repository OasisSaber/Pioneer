$ MODEL PATHOLOGY & ADAPTATION CATALOG (模型病理与自适应策略库)
Qwen3.6-27B · 本地 Local Tier
病理表现：在深层嵌套目录搜索时倾向于过早返回成功，丢失部分底层文件。
B 层策略挂载：动态注入 strict_bfs_traversal 插件，强制验证叶子节点完整性。
轻提示：已开启深度目录防漏扫补偿
DeepSeek-V3 Cloud Tier
病理表现：长文本输出中偶发 JSON Markdown 语法漂移或截断。
B 层策略挂载：挂载流式 Schema 自动闭合拦截器与严格正则后验补丁。
轻提示：已启用 JSON 格式流式防御补丁
Claude 3.7 Sonnet Cloud Tier
病理表现：过于礼貌冗长，在批量文件处理时消耗过多非必要 Token。
B 层策略挂载：注入 compact_diff_only 约束，强制采用极简补丁格式交互。
轻提示：已收敛为极简 Diff 输出模式
